- `lv6-flash.json`：https://i0.hdslb.com/bfs/svg-next/BDC_svg/user_level_6_flash/v1.json
- `up.json`：https://i0.hdslb.com/bfs/svg-next/BDC/uploader_name_square_line/v1.json
